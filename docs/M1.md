# M1 — Windows Alpha

> 状态：**进行中**。始于 2026-11-19。范围见 [PLAN.md](PLAN.md) §4。

M1 的目标是把 M0 验证过的东西做成产品：一个**以媒体库为中心**的 Windows 客户端——
多个资源库统一接入、一次搜索全都能找到、能播、能续看、能打包。
**共享逻辑在 `core/media`（Rust），WPF 只做界面**（ADR-0008），
所以这里做完的媒体库能力 Android / TV / macOS 直接复用。

格式覆盖（DV / HDR / 解码矩阵）是另一条主线，见 [PLAN.md](PLAN.md) §4 的能力矩阵与
[DECODE.md](DECODE.md)。

## 2. 已知缺口

- **单集详情拿不到**：飞牛 `/item/<episode>` 返回 `{}`，所以单集没有简介/演职员，
  只有列表项里的剧照和时长；
- **多季只显示本地有的季**：样本里 TMDB 写 10 季、本地只有 1 季，
  详情页按本地季数显示（`81 集`），避免点开一个空季；
- **首播季没有自动跳转**：续播点在第 3 季时，进详情页仍停在第一季
  （`play_item_guid` 对剧集常为空，拿不到位置）；
- **没有搜索**：库内搜索、跨源合并搜索都还没做；
- **DV 徽标不在产品壳里**：M0 验证壳 `DvPlayer.Windows` 有，正式壳还没搬；
  按 ARCHITECTURE §2.2 的原则，播放页最终要显示「源格式 → 实际输出」；

## 3. 下一步顺序

1. `EmbySource`（实现 `MediaSource` + `create()` 加分支 + `SUPPORTED_KINDS` 注册），
   Jellyfin 复用同一适配器；
2. `MediaHub` 聚合层：多源同时连接、按 `<sourceId>:<itemId>` 寻址、
   合并播放记录、合并搜索、跨源去重与选源（ARCHITECTURE §1.2）；
3. 播放控制补齐：音轨/字幕面板（mpv `track-list`）、全屏、HDR 开关、音频直通；
4. 格式矩阵补齐：AV1 / PGS / HDR 直通到 HDR 屏、音频直通实测（DECODE.md）；
5. MSIX 打包与自动更新；
6. Plex 与 SMB / NFS / WebDAV 目录源。
