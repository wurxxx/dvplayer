# M1 — Windows Alpha

> 状态：**基本完成**（2026-11-21）。B1–B13、B16 已通过；剩 B10 的
> Emby / Jellyfin 播放联调、B14 打包、B15 Plex，缺口见 §2。范围见 [PLAN.md](PLAN.md) §4。

M1 的目标是把 M0 验证过的东西做成产品：一个**以媒体库为中心**的 Windows 客户端——
多个资源库统一接入、一次搜索全都能找到、能播、能续看、能打包。
**共享逻辑在 `core/media`（Rust），WPF 只做界面**（ADR-0008），
所以这里做完的媒体库能力 Android / TV / macOS 直接复用。

格式覆盖（DV / HDR / 解码矩阵）是另一条主线，见 [PLAN.md](PLAN.md) §4 的能力矩阵与
[DECODE.md](DECODE.md)。

## 2. 已知缺口

- **单集详情拿不到**：飞牛 `/item/<episode>` 返回 `{}`，所以单集没有简介/演职员，
  只有列表项里的剧照和时长；
- **多季只显示本地有的季**：样本里 TMDB 写 10 季、本地只有 1 季，
  详情页按本地季数显示（`81 集`），避免点开一个空季；
- **首播季没有自动跳转**：续播点在第 3 季时，进详情页仍停在第一季
  （`play_item_guid` 对剧集常为空，拿不到位置）；
- **FEL / MEL 不分**：播放页徽标只到 `DV P7`，要区分 FEL / MEL 得侧路
  `ffmpeg` + `dovi_tool` 读第一个 RPU（M0 验证壳里做过）；
- **Emby / Jellyfin 播放链路未联调**：播放直链与进度回写还没在真实服务器验证，
  见 [EMBY-API.md](EMBY-API.md) §5；
- **macOS 侧差三项开关**：音频输出 / 音频直通 / HDR 直通是 Windows 先做的，
  macOS 播放页「更多」里还没有（两端其余功能已对齐）。
